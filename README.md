# 中国近代史纲要 · 刷题系统

两套题库（PDF 1238 题 + Word 884 题）剔除重合后合并而成，共 **1313 题**：
- 单选题 599
- 多选题 271
- 判断题 443

## 功能

| 模块 | 说明 |
|---|---|
| 模拟考试 | 随机组卷 100 题（60 单选 + 20 多选 + 20 判断），选完即出答案与解析，交卷出总分 |
| 总题库 | 全部题目，可按题型、章节筛选，支持关键词搜索，点击即答即判 |
| 分章节题库 | 导言 / 第一~十章 / 二十大 / 综合补充，逐章刷题 |
| 错题本 | 所有答错的题自动收录，重做答对自动移出，可一键清空 |
| 考试记录 | 每次模拟考自动保存，可回看整卷（你的答案 / 正确答案 / 解析），可删除 |

数据保存在浏览器 localStorage 中，换浏览器或清除浏览器数据会丢失记录。

## 使用

直接双击打开 `index.html` 即可（无需联网、无需安装）。

也可以在目录下起一个静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 数据说明

- `data/questions.js` 由 `../work/assemble.py` 从 `../work/questions.json` 生成，题目 id 稳定，错题本/考试记录按 id 存储。
- PDF 独有且原卷无选项的约 200 道选择题，干扰项为人工补全（正确选项置于原答案字母位），章节归入「综合补充」。
- 两卷答案冲突处已逐题按教材口径人工校核（38 处），详见 `../work/fixes.json`。
- 修改题目后需重跑 `python -I assemble.py`（在 `../work` 目录下），再刷新页面。
